# 高德地图界面精简 · Rootless

适用：高德地图 17.00.2、iPhone 14 Pro / iOS 16.5 / Dopamine 原版。

安装包：`packages/local.gaode.clean_0.3.1_iphoneos-arm64.deb`。仅向 `com.autonavi.amap` 注入，其他版本不启用。无需重签或重装 IPA。

## 0.3.1 行为

- 首页保留地图与原生搜索框，移除搜索框下方快捷入口、常用地点及推荐面板；隐藏搜索框推广文字和 `template_rank` 扫街榜挂件。
- 底栏仅保留首页、我的。底栏恢复原生完整长度，两项按钮保留0.3.0窄底栏时的居中位置（393pt视口下中心间距120pt）；原生选中背景随按钮更新。
- 我的保留账户资料与足迹卡片，卡片下方使用不透明区域覆盖，限制纵向滚动，接住空白区域触摸，避免操作穿透到底层地图。
- AJX 元素更新与页面布局中同步更新隐藏区域。冷启动复用同宽视口上次实际识别的足迹边界，随后重新校准；不会用全屏遮挡等待标签加载。首次没有缓存时依赖同步标签识别，不承诺所有服务端布局均无闪现。

这是显示层修改，不拦截网络请求，也不保证停止推荐数据后台加载。服务端布局变化仍可能需要适配。没有硬编码账号、位置、SSH 地址或密码。

## 安装与回退

通过 Sileo 等包管理器安装 deb，可直接覆盖旧版。退出并重新打开高德。卸载 **Gaode Clean (Rootless)** 后重新打开高德即可恢复。

这是 rootless 包，安装路径在 `/var/jb`，不是 RootHide 包。deb 架构 `iphoneos-arm64`，动态库包含 arm64 与 arm64e。

## 验证范围

0.3.1仅本地构建，未安装或真机验证底栏新布局。0.3.0已检查两页真机截图、两项底栏配置与窄底栏几何、我的空白区不透明属性和触摸命中。Clang 静态分析无诊断；滚动范围测试通过，包括 20,001 个偏移值。最终包不含应用内测试请求入口。

最后一轮修复取消了冷启动整页遮挡。尚需用户实际快速切换确认冷启动体验；未完成逐帧录像、完整搜索导航流程、深色模式及长期稳定性回归。应用自身加载账户和足迹数据的耗时不由此插件消除。

## 构建与源码

```sh
bash scripts/build.sh
```

需要 Xcode iPhoneOS SDK、Theos、ldid。默认 Theos 为 `/Users/yanghuai/theos`；可传入 `THEOS=/your/theos`。脚本在英文临时路径构建以避开 Theos 中文路径问题。

- `src/GaodeClean.m`：Objective-C 运行时 hook、受限页面匹配与布局处理。
- `src/GCCGeometry.h`、`tests/geometry.c`：滚动边界函数与测试。
- `analysis/REPORT.md`：版本演进与分析依据。

`GCC_DEVICE_TEST=1` 仅用于开发期设备检查，交付包不启用。真机截图与诊断可能含个人页面信息，已加入忽略规则，不用于分发。
